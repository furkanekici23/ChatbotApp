# ChatbotApp

ChatbotApp, kullanıcılarla doğal dilde etkileşim kurabilen bir C# ile geliştirilmiş bir chatbot uygulamasıdır. Bu proje, basit bir chatbot oluşturmak isteyenler için temel bir yapı sunar ve daha gelişmiş özellikler eklemek için genişletilebilir bir mimari sağlar.

## Özellikler

- Kullanıcıdan metin girişlerini alır ve önceden tanımlanmış cevaplar verir.
- C# ile geliştirilmiş temiz ve modüler kod yapısı.
- Yeni özellikler ve cevaplar kolayca eklenebilir.
- Kullanıcı dostu bir arayüz ile etkileşim.

## Gereksinimler

- **.NET Framework 4.7.2** veya daha yeni bir sürüm
- **Visual Studio 2022** veya daha yeni bir sürüm
- **NuGet Paket Yöneticisi** (gerekli bağımlılıkları yüklemek için)

## Kurulum

1. **Depoyu klonlayın**  
   ```bash
   git clone https://github.com/civanaban2/ChatbotApp.git
   cd ChatbotApp
   ```

2. **Proje dosyasını açın**  
   Visual Studio'yu açın ve `ChatbotApp.sln` dosyasını yükleyin.

3. **Bağımlılıkları yükleyin**  
   Projede kullanılan NuGet paketlerini yüklemek için Visual Studio'da **Tools > NuGet Package Manager > Manage NuGet Packages for Solution...** yolunu izleyin.

4. **Uygulamayı çalıştırın**  
   Visual Studio'da `F5` tuşuna basarak projeyi başlatın.

## Kullanım

1. Uygulama başlatıldığında bir giriş ekranı açılır.
2. Kullanıcı, mesajını yazarak chatbot ile etkileşim kurabilir.
3. Chatbot, verilen girişe uygun bir cevap döndürür.

## Geliştirme Planı

Gelecekte aşağıdaki özelliklerin eklenmesi planlanmaktadır:

- Daha gelişmiş doğal dil işleme (NLP) yetenekleri.
- Veritabanı entegrasyonu ile öğrenen chatbot yapısı.

- Web ve mobil platformlara taşınabilirlik.
